# TSPL(The success point library)

### Library Management System

A full-stack Library Management System built with **Laravel**, covering both frontend and backend functionality.

* Users can search for available seats and book a seat online.
* Displays **real-time seat availability**, including occupied and vacant seats.
* Shows which student has booked/occupied a particular seat.
* Generates an **invoice/booking receipt** after successful seat booking.
* Provides booking and student-related details through a centralized management system.
* Built using **Laravel, PHP, MySQL, HTML, CSS, JavaScript, and Bootstrap**.
